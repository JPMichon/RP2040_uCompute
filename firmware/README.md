# Notes
Il n'y a pas encore de firmware officiel pour le projet. Il est possible d'utiliser un firmware supportant le driver W5500 pour le support réseau.
Comme la taille du SPI est hardcoder dans le firmware, selon le SPI installer sur le board, il ce peux que vous n'ayez pas un accès complet au stockage optimal. <BR>
## Source du firmware.
https://micropython.org/download/W5500_EVB_PICO/
